# Argentina Specialty Coffee Data Platform

Data platform for collecting, transforming, and analyzing specialty coffee data from Argentina.

## Project Goals

- Collect specialty coffee data
- Build data ingestion pipelines
- Store raw and processed data
- Transform data using Python and SQL
- Load analytical data into Google BigQuery
- Build a scalable data architecture on Google Cloud Platform

## Technologies

- Python
- SQL
- Google Cloud Platform
- BigQuery
- GitHub
